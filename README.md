## 📖 About The Game

**Day** is an interactive Visual Novel where players navigate through a warm and atmospheric narrative. Every choice made shapes the storyline and leads to different outcomes and character interactions.

- **Genre:** Visual Novel / Slice of Life / Interactive Fiction
- **Engine:** [Ren'Py Engine](https://www.renpy.org/)
- **Platform:** Windows / macOS / Linux / Web (Itch.io)

---

## 🛠️ How It Was Made & Tools Used

This project was built from scratch as an exploration into interactive storytelling and basic game logic:

- **Engine & Logic:** Built using **Ren'Py** (Python-driven Visual Novel Engine) to handle scene transitions, dialog scripts, and decision branching.
- **Code Editor:** **Visual Studio Code** for editing `.rpy` scripts and organizing code logic.
- **Art & Design:** Custom character art, backgrounds, and visual assets designed using **ibisPaint X**.
- **Tutorials & Resources:** Followed the official Ren'Py documentation and community tutorials to learn script branching, UI customization, and asset integration.

---

## 💡 What I Learned & Challenges Overcame

### 📚 What I Learned:
- **Story Branching:** Understanding how conditional statements (`if`, `else`, `label`, `menu`) structure interactive choices in Ren'Py.
- **UI Customization:** Modifying `gui.rpy` and `screens.rpy` to give the game a cohesive aesthetic.
- **Asset Pipeline:** Importing custom visual assets and aligning them with screen dimensions and text positions.

### 🧩 Challenges & Obstacles:
- **Branching Logic:** Managing multiple choice paths without breaking scene transitions or looping dialogue unintentionally.
- **GUI Alignment:** Customizing the default Ren'Py interface to fit the art style required troubleshooting screen parameters and asset dimensions.
